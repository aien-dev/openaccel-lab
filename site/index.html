OpenAccel Lab

A vendor-neutral, execution-verified conformance and performance lab for accelerator kernels. Every workload has one float64 reference oracle, a written tolerance contract and the same seeded inputs for every entrant. The entrants are OpenCL C, Triton, HIP, CUDA and Omega; none is privileged. Wrong kernels are kept in the lab as controls, and the board shows them being caught.

Read this before reading the numbers. CI timings are host CPU wall-clock times on GitHub runners (OpenCL on PoCL, Triton in its interpreter, HIP on HIP-CPU, Omega native AArch64). They show distributions for one runner and are not GPU performance. GPU rows appear only from labelled receipts, each linked to its evidence. Timings are shown as min / p10 / p25 / median / p75 / p90 / max with the sample count, never as means.

Conformance matrix

Cell: status over every case and seed (count), and the median share of the tolerance bound used (err ratio; 0 = bit-exact, 1 = at the bound). COMPILED means the CUDA source built with nvcc on a runner with no GPU and was not run.

Negative controls

Each control is a workload with one defect written into every entrant (a dropped term, an exclusive scan, a softmax without max subtraction). Green means the lab flagged it on that backend; red means a wrong kernel passed.

Cross-backend agreement

For each workload: how many cases produced 1, 2, 3 or more distinct output byte streams across backends. Bitwise agreement is not required, only the tolerance contract; this shows where entrants differ in rounding.

Timing distributions (default case)

Box: p25 to p75, line at median; whiskers p10 to p90; dots min and max. Log scale, nanoseconds.

Minimised failures

For every failing record the CI runs oal-shrink, which reduces the shape while the failure persists and prints the command that reproduces it.

GPU receipts

Rows from real GPUs. Each row carries its provenance label; none of them is a CI result.
